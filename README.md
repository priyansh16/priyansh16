## Core Expertise

- **Data Engineering**: designing ingestion pipelines with explicit, defensible data quality policies, idempotent processing, and layered validation from the API boundary down to the database.
- **Production ML Infrastructure:** end-to-end ML lifecycles, from data acquisition through deployment via REST APIs, with health monitoring, alerting, and drift detection built in from the start.
- **Behavioral & Recommendation Modeling:** unsupervised learning (NMF, GMM) for entity clustering and evolution tracking; two-tower architectures for large-scale retrieval and ranking.
  
- **Observability**: rolling-threshold anomaly detection, alerting pipelines, and incident response for globally distributed systems.

## Selected Work
- **[Messy Data Ingestion Pipelines](https://github.com/priyansh16/messy-data-ingestion):** Two production-style ingestion pipelines (FastAPI, SQLAlchemy, PostgreSQL) built around explicit data quality policies, idempotent inserts, and layered validation, with a pytest suite covering the edge cases those policies depend on.
- **[RAG Data Infrastructure Platform](https://github.com/priyansh16/research-rag):** End-to-end document ingestion, retrieval, and generation platform with sub-30ms retrieval latency via a dual-storage pattern separating vector search from structured metadata lookup, and component-level health monitoring across the pipeline.
- **[Swedish Property Valuation Platform](https://github.com/priyansh16/PricePrediction):** Full-stack Flask application with a trained XGBoost/Random Forest regression model tracked via MLflow, deployed on AWS with a monitoring endpoint for prediction drift and feature distribution shifts.
